# Tidemark · Marine Risk Intelligence

Ocean and coastal risk intelligence platform for capital allocators, underwriters, and decision-makers.

## Deploy in 3 steps

### Option A — Vercel (recommended, free)

1. Upload this folder to GitHub (drag-and-drop at github.com/new)
2. Go to vercel.com → "Add New Project" → import your GitHub repo
3. Click Deploy — live URL in ~60 seconds

Your URL will be: `https://tidemark.vercel.app` (or similar)

### Option B — Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Features

- **Live Intelligence** — real-time marine conditions from Open-Meteo (Copernicus/DWD), GEBCO bathymetry map
- **Risk Screener** — 5-dimension ocean risk assessment with deep scientific context
- **Project Scorer** — AI-powered due diligence memo (requires Anthropic API)
- **Pipeline Tracker** — compare and track multiple assessments

## Data Sources

IPCC AR6 · IPBES · GBF · TNFD · NOAA · Copernicus Marine Service · GEBCO 2025 · FAO · UNEP-WCMC · WorldRiskIndex · Open-Meteo Marine API
